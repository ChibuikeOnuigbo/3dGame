# HOLLOW CURRENT — Game Design

## Identity
First-person survival/action horror. You are a night contractor sent to restart Pump Station 7 after a pressure event. The water system is alive with something that moves through pipes. Security drones still patrol. You restore power, reroute valves, survive night pressure, and open the sea-gate to leave.

Not Backrooms. Not a generic FPS. Not jump-scare spam.

## Pillars
Responsive movement, dense authored spaces, environmental story, fair threats, lighting/audio as gameplay, remappable controls, save/load.

## Loop
Explore → observe → interact → solve (power/valves) → survive patrols/night → unlock area → repeat.

## Threats
- **Sentinel drones**: LOS + hearing, patrol, investigate, chase, lose target.
- **Pipe pressure entity**: silhouette in steam, no face; corridor crush event.
- **Hazards**: live cables, crush gate, steam, collapsing grate.

## Controls (defaults, remappable)
WASD, mouse look, Shift sprint, C crouch, Space jump, E interact, F flashlight, Esc pause.

## Progression
1. Reception / lockdown
2. Restore generator
3. Lab keycard
4. Valve puzzle / shrinking corridor
5. Outdoor yard at night
6. Sea-gate escape
